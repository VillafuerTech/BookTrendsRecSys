\begin{abstract}
\noindent
\textbf{BookTrendsRecSys} is a compact recommendation system that produces a Top--10 list tailored to a reader. The end-to-end pipeline spans \emph{data collection} (Goodreads reviews $\rightarrow$ user rating histories), \emph{data preparation} and EDA, an \emph{implicit-feedback ALS} model, \emph{offline evaluation} with ranking metrics (P@10, R@10, NDCG@10), a descriptive \emph{fairness snapshot}, and a \emph{Streamlit} app. Final test metrics: P@10=\textbf{\Pten}, R@10=\textbf{\Rten}, NDCG@10=\textbf{\NDCGten}; validation NDCG@10=\textbf{\ValNDCGten}. Parity gaps: region=\textbf{\ParityGapRegion}, genre=\textbf{\ParityGapGenre}. We emphasize strict split hygiene, resumable crawling, and reproducibility.
\end{abstract}

\section{Introduction}
We optimize for short-list quality rather than rating error: P@10 (share of good picks among 10), R@10 (coverage within 10), NDCG@10 (order-aware list quality). Hyperparameters are selected on validation NDCG@10; seed is 42.

\section{Data Collection and Crawling Strategy}
\textbf{Layout \& scripts.}
\begin{ttfamily}\small
/scripts \\
\quad get\_rating\_of\_users.py \quad\# Fetch rating lists for users from review files \\
\quad get\_rating\_of\_books.py \quad\# Fetch ratings for books based on a list of book\_ids \\
\quad build\_goodreads\_dataset.py \quad\# Merge all rating files into a unified dataset \\
\quad count\_books.py \quad\# Count the number of books reviewed by users \\
\quad goodreads\_reviews\_\_{book\_id}.json \quad\# Original review files containing user\_id \\
\quad goodreads\_ratings\_{\{user\_id\}}.json \quad\# Rating results for individual users \\
\quad goodreads\_dataset.csv \quad\# Merged training dataset (userid, bookid, rating)
\end{ttfamily}

\noindent\textbf{Workflow.} Start from popular book lists (seeds) $\rightarrow$ scrape book review pages to extract \texttt{user\_id}s $\rightarrow$ visit each user’s rating history (if public) $\rightarrow$ aggregate to \texttt{(userid, bookid, rating)} with timestamps and shelves when available.

\noindent\textbf{Parsing \& selectors.} Robust CSS queries with fallbacks: review rows via \texttt{tr.bookalike.review} (fallback \texttt{table\#books tr}); ratings via \texttt{.ShelfStatus span[aria-label*="out of 5"]} to extract star counts; titles/IDs from title cells else cover cells/anchors. Handle alternate layouts.

\noindent\textbf{Network hygiene.} Use a \texttt{requests.Session} with \texttt{HTTPAdapter}+Retry for 429/5xx; randomized delays; cookies and headers; pagination until no new rows or a safe cap. Resume-safe: skip existing JSON unless overwriting; validate after write.

\noindent\textbf{Schemas.} Book review JSON: \texttt{\{book\_id, book\_title, average\_rating, reviews:[\{user, user\_id, user\_rating, review\_date, review, likes, comments\}], fetched\_at\}}. User ratings JSON: \texttt{\{source\_user\_id, count, items:[\{book\_id, book\_title, book\_url, author, user\_rating\_text, user\_rating, date\_read, date\_added, shelves, review\_url\}]\}}. Ethics/ToS: public data only, rate-limit, minimal PII.

\section{Model: Implicit ALS}
We use Hu--Koren--Volinsky implicit ALS. With preference $p_{ui}\in\{0,1\}$ and confidence $c_{ui}=1+\alpha r_{ui}$, we solve:
\[
\min_{X,Y}\sum_{u,i}c_{ui}\bigl(p_{ui}-x_u^\top y_i\bigr)^2+\lambda(\lVert x_u\rVert^2+\lVert y_i\rVert^2),
\]
via alternating least-squares. Chosen hyperparameters: rank=\textbf{\RankParam}, reg=\textbf{\RegParam}, alpha=\textbf{\AlphaParam}, iters=\textbf{\ItersParam}.

\section{Evaluation}
For user $u$ with ground truth $G_u$ and top-$K$ list $R_u=[i_1,\dots,i_K]$ ($K{=}10$):
\[
\mathrm{P@K}=\frac{1}{|U|}\sum_u\frac{|R_u\cap G_u|}{K},\quad
\mathrm{R@K}=\frac{1}{|U|}\sum_u\frac{|R_u\cap G_u|}{|G_u|},
\]
\[
\mathrm{DCG@K}(u)=\sum_{j=1}^K\frac{\mathbf{1}[i_j\in G_u]}{\log_2(j+1)},\quad
\mathrm{NDCG@K}=\frac{1}{|U|}\sum_u\frac{\mathrm{DCG@K}(u)}{\mathrm{IDCG@K}(u)}.
\]
